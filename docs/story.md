# LAST WORLD — โครงเรื่องและรายการฉาก

สถานะ: ทั้ง 30 ฉากทำเป็นอนิเมชั่นและต่อเข้าเกมแล้ว (โค้ดอยู่ใน `src/story/`) โครงเรื่องดูข้อ 10 บทพูดดูข้อ 11 วิธีทดสอบดูข้อ 12
ลำดับงาน: โครงเรื่อง (ไฟล์นี้) → บทพูดทุกบรรทัด → ต่อเข้าเกมด้วยฉากนิ่ง → อนิเมชั่นทำหลังสุด

## 1. เรื่องย่อในสามประโยค

โลกแตกเป็นแดนลอยจาก "การแตกสลาย" (The Sundering) และปาร์ตี้เดินทางผ่านหกแดนเพื่อปิดประตูอเวจี โดยมีนักทำแผนที่ชราคนหนึ่งนำทางให้ตลอด
ที่ด่าน 6 เขาเปิดเผยตัวว่าเป็นจอมมาร Xal'Zhul เอง: บอสทุกตัวที่ปาร์ตี้ฆ่าคือสมอที่ยึดแดนนั้นไว้ และแผนที่ที่เขาให้คือรายการสิ่งที่เขาจะกลืน
แต่เขากลืนแดนต่าง ๆ เพื่อซ่อนมันจากผู้สร้างโลกที่กำลังลบโลกทิ้งทีละหน้า และหลังเขาตาย แผนที่ของเขาคือสิ่งเดียวที่นำปาร์ตี้ไปถึงผู้สร้างได้

## 2. สิ่งที่ใช้จากเกมที่มีอยู่แล้ว

เรื่องนี้ไม่ขัดกับข้อความใดในเกมตอนนี้ และตั้งใจต่อยอดจากมัน:

| ของเดิมในเกม | ใช้ในเรื่องอย่างไร |
|---|---|
| เหตุการณ์ "Wounded Traveler" (นักทำแผนที่บาดเจ็บข้างเกวียน) | กลายเป็นตัวละครหลัก: ออร์ริน นักทำแผนที่ |
| คำนำด่าน 5: มังกร "ตัดสินทุกคนที่หาทางไปอเวจี" | มังกรรู้ว่าแผนที่เป็นของใคร จึงขวางปาร์ตี้ |
| คำนำด่าน 6: Xal'Zhul "กลืนแดนลอยทีละแดน" | การกลืนเกิดขึ้นทุกครั้งที่บอสตาย |
| คำพูด Xal'Zhul: "ทุกโลกล้วนมีจุดจบ ของเจ้าเป็นเพียงโลกสุดท้าย" | เป็นประโยคเปิดเผยตัว และมีความหมายที่สองในองก์ 2 |
| บทส่งท้ายด่าน 6: "ประตูบานหนึ่งเปิดขึ้น" | ประตูนั้นคือสิ่งที่เขาซ่อนไว้ ไม่ใช่สิ่งที่เขาเฝ้า |
| ด่าน 11: Aeon "ลบโลกทีละหน้า" และปากกาหล่นจากมือ | แผนที่ (สิ่งที่วาด) ปะทะปากกา (สิ่งที่ลบ) |
| เหตุการณ์ "Restless Spirit" | วิญญาณที่จำหน้าออร์รินได้ |
| ฉากเดินทางระหว่างแดน และแผนที่โลก | ที่อยู่ของ "บันทึกขอบแผนที่" ในองก์ 2 |

## 3. ตัวละคร

- **ปาร์ตี้** — ไม่มีชื่อตายตัว ใช้ตัวละครจริงของผู้เล่น 1–4 คน บทพูดแบ่งตามตำแหน่ง: *คนนำ* พูดบทหลัก, *คนที่สอง* พูดบทสงสัย/เสริม, ที่เหลือแสดงท่าทาง เล่นคนเดียวให้คนนำพูดบทของคนที่สองด้วย
- **ออร์ริน (Orrin) นักทำแผนที่** — ชายชราใจดี มือขวาพันผ้าไว้ตลอด ให้แผนที่ของแดนถัดไปเสมอ ชื่อเปลี่ยนได้
- **Xal'Zhul** — ร่างจริงของออร์ริน ไม่ใช่ปีศาจที่อยากทำลาย เป็นผู้ที่เลือกวิธีเลวร้ายเพื่อเก็บโลกไว้
- **บอสด่าน 1–5** — "สมอ" ผู้พิทักษ์ที่ยึดแดนของตัวเองไว้ และเสียสติเพราะต้านแรงดึงของอเวจีมานาน
- **บอสด่าน 7–10** — สิ่งที่ผู้สร้างทิ้งไว้แล้วยังทำหน้าที่ต่อโดยไม่มีใครสั่ง
- **Aeon ผู้ลบ** — ผู้สร้างโลกที่เบื่อผลงานของตัวเอง

## 4. เบาะแสที่ต้องปูก่อนเปิดเผย

ผู้เล่นที่ย้อนดูต้องเห็นว่าคำตอบอยู่ตรงหน้าตลอด ทุกเบาะแสต้องปรากฏในฉากตามตาราง:

1. **แผลที่ไม่หาย** — มือขวาพันผ้าตั้งแต่ด่าน 1 ถึงด่าน 5 ผ้าผืนเดิม เลือดยังสด (ด่าน 6 เขาแกะผ้าออก ข้างในคือความว่างเปล่า)
2. **เขาไปถึงก่อนเสมอ** — ปาร์ตี้ไม่เคยเห็นเขาเดินทาง แต่เขารออยู่ที่แดนถัดไปทุกครั้ง
3. **การลงหมึก** — ทุกครั้งที่บอสตาย เขาลงหมึกทับแดนนั้นบนแผนที่ แล้วแดนนั้นเงียบผิดปกติ (ด่าน 3 เห็นชัดว่าสีซีดลง)
4. **บอสรู้จักแผนที่** — ด่าน 1 พูดไม่จบประโยค, ด่าน 3 พูดตรง ๆ, ด่าน 5 บอกความจริงทั้งหมด
5. **คนตายจำเขาได้** — วิญญาณที่ด่าน 4 เห็นหน้าเขาก่อนการแตกสลาย
6. **แผนที่มีแดนที่ไม่มีอยู่แล้ว** — รอยหมึกดำเป็นหย่อม ๆ ที่เขาบอกว่า "หมึกหก"
7. **ชาที่เขาไม่เคยดื่ม** — เขาต้มชาขมให้ปาร์ตี้ทุกครั้งที่พบกัน ใบชามาจากแดนที่ไม่มีอยู่แล้ว และถ้วยของเขาเองไม่เคยพร่อง เป็นมุกประจำเรื่องที่กลับมาเจ็บในฉาก 6C และ 11D

## 5. องก์ 1 — แผนที่ของคนแปลกหน้า (ด่าน 1–6)

รหัสฉาก: เลขด่าน + A (ระหว่างสำรวจ) / B (ก่อนสู้บอส) / C (หลังชนะบอส)
ระดับ: **หลัก** = ขาดแล้วเรื่องไม่ต่อ, **รอง** = เพิ่มน้ำหนัก, **เสริม** = ทำถ้ามีเวลา

| รหัส | ชื่อฉาก | เกิดอะไรขึ้น | ประโยคสำคัญ | ระดับ |
|---|---|---|---|---|
| 0 | โลกสุดท้าย | สามภาพ: โลกเดิม, การแตกสลาย, แดนลอย ปาร์ตี้ยืนที่ขอบป่า | "ที่เหลืออยู่มีแค่นี้" | หลัก |
| 1A | คนแปลกหน้าริมทาง | พบออร์รินบาดเจ็บข้างเกวียน ช่วยแล้วได้แผนที่ป่า เขาขอให้ปลดปล่อยผู้พิทักษ์ที่เสียสติ | "มันทรมานมานานแล้ว ช่วยให้มันได้พักเถอะ" | หลัก |
| 1B | ผู้พิทักษ์ป่าตื่น | บอสดันตัวขึ้นจากดิน (ตัวอย่างที่ทำแล้ว) | "ผู้บุกรุก!!" | รอง |
| 1C | หมึกหยดแรก | ผู้พิทักษ์ล้ม พูดไม่จบ ออร์รินมาถึง ลงหมึกบนแผนที่ ป่าเงียบสนิท | ผู้พิทักษ์: "อย่าให้เขา...วาด..." | หลัก |
| 2A | กองไฟที่โอเอซิส | ออร์รินรออยู่ก่อนแล้ว เล่าเรื่องสงครามของเทพ มือยังพันผ้าเดิม | คนที่สอง: "ลุงมาถึงก่อนเราได้ยังไง" | รอง |
| 2B | ทรราชใต้ทราย | บอสโผล่จากเนินทราย | "ทะเลทรายกลืนอาณาจักรมาแล้ว" | เสริม |
| 2C | ภาพบนผนังถ้ำ | ในรังบอสมีภาพเขียนโบราณ: เหล่าเทพ และคนถือม้วนแผนที่ ปาร์ตี้ไม่เข้าใจ | (ไม่มีบทพูด ใช้ภาพ) | รอง |
| 3A | เมืองที่หยุดนิ่ง | ชาวเมืองถูกแช่แข็งกลางท่าทาง ยังมีชีวิต ราชินีแช่ทั้งอาณาจักรเพื่อไม่ให้ใครเอาไปได้ | "นางไม่ได้ฆ่าพวกเขา นางเก็บพวกเขาไว้" | รอง |
| 3B | ราชินีเห็นแผนที่ | ก่อนสู้ ราชินีจ้องแผนที่ในมือปาร์ตี้ | "เจ้าถือแผนที่ของมัน แล้วยังกล้าเรียกข้าว่าปีศาจ" | หลัก |
| 3C | น้ำแข็งละลาย สีก็ละลาย | ออร์รินลงหมึก อาณาจักรซีดจางลงต่อหน้า คนที่สองเริ่มสงสัย | คนที่สอง: "เมื่อกี้มัน...จางลงใช่ไหม" | หลัก |
| 4A | วิญญาณที่จำหน้าได้ | วิญญาณในสุสานเห็นออร์รินเดินผ่านที่นี่ก่อนการแตกสลาย หน้าเดิม | "ชายพันมือคนนั้น ข้าเห็นเขาตอนโลกยังเป็นผืนเดียว" | รอง |
| 4B | ราชาผู้จดจำ | ลิชปลุกคนตายเพื่อให้ยังมีใครจำแดนที่หายไปได้ | "ถ้าข้าหลับ ใครจะจำพวกเขา" | เสริม |
| 4C | คำถามที่ไม่ได้คำตอบ | ปาร์ตี้ถามออร์รินตรง ๆ เขาตอบความจริงครึ่งเดียว แล้วเดินนำไปก่อน | "ข้าแค่จดสิ่งที่กำลังจะหายไป" | หลัก |
| 5B | คำตัดสินของดวงดาว | มังกรไม่ยอมให้ผ่าน เพราะปาร์ตี้ถือแผนที่ของเจ้าแห่งอเวจี | "เจ้าพาแผนที่ของนายมันมาถึงประตูข้า" | รอง |
| 5C | สมอเส้นสุดท้าย | มังกรใกล้ตายบอกความจริง: ผู้พิทักษ์ทั้งห้าคือสมอ ปาร์ตี้ตัดมันเองทั้งหมด แผนที่ไหม้เป็นสีดำ ออร์รินยืนบนสะพานแสง | ออร์ริน: "ขอบใจ ที่เปิดทางให้" | หลัก |
| 6A | แผนที่ที่เหลือแดนเดียว | เดินเข้าป้อม เสียงเขาดังตามผนัง แผนที่เหลือแค่แดนที่ปาร์ตี้ยืนอยู่ | "เดินมาสิ ทางนี้เจ้ารู้จักดี ข้าวาดให้เองทุกเส้น" | รอง |
| 6B | ผ้าพันมือ | ออร์รินนั่งบนบัลลังก์ แกะผ้าออก ข้างในคือความว่างเปล่า ร่างเปลี่ยนเป็น Xal'Zhul | "ทุกโลกล้วนมีจุดจบ ของเจ้าเป็นเพียงโลกสุดท้าย" | หลัก |
| 6C | สิ่งที่อยู่ในท้อง | เขาล้ม กลับเป็นชายชรา บอกว่ากลืนแดนต่าง ๆ เพื่อซ่อนจากผู้ลบ ยื่นแผนที่แผ่นจริงให้ แดนทั้งหมดไหลกลับออกมา ประตูเปิด | "ข้าไม่ได้ทำลายมัน ข้าเก็บมันไว้ในที่ที่ปากกาเอื้อมไม่ถึง" | หลัก |

**ความหมายของชื่อองก์:** ผู้เล่นคิดว่า "โลกสุดท้าย" คือโลกที่ต้องปกป้องจากจอมมาร แต่จริง ๆ มันสุดท้ายเพราะมีคนกำลังลบโลกอยู่ และจอมมารรู้เรื่องนี้ก่อนใคร

## 6. องก์ 2 — หน้าสุดท้าย (ด่าน 7–11)

ออร์รินตายแล้ว แต่แผนที่ของเขายังพูด: ทุกแดนใหม่จะมี **บันทึกขอบแผนที่** ลายมือเขาปรากฏขึ้นเอง
ห้าแดนนี้คือแดนที่เขาซ่อนลึกที่สุด บอสไม่ใช่สมอที่เสียสติ แต่เป็นสิ่งที่ผู้สร้างทิ้งไว้แล้วยังทำงานต่อ
แก่นของเรื่อง: **ของที่ถูกทิ้งควรทำอะไรต่อ เมื่อคนสร้างไม่ต้องการมันแล้ว**

|---|---|---|---|---|
| 7N | บันทึก: ใต้ราก | ระหว่างเดินทาง ลายมือออร์รินปรากฏบนแผนที่ | "ข้าซ่อนที่นี่ไว้ก่อนที่อื่น เพราะมันยังเติบโตอยู่" | รอง |
| 7B | มารดาผู้กินทุกอย่าง | บอสกินทุกสิ่งที่ตายเพื่อไม่ให้อะไรหายไป (ทำแบบเดียวกับออร์ริน) | "ทุกสิ่งที่ล้มที่นี่ ยังอยู่ในตัวข้า" | เสริม |
| 8N | บันทึก: เมืองที่ไม่หยุด | | "คนสร้างตายหมดแล้ว แต่ไม่มีใครบอกเครื่องจักร" | เสริม |
| 8B | ผู้สำเร็จราชการเหล็ก | เครื่องจักรที่ทำงานต่อโดยไม่มีเจ้านาย เห็นปาร์ตี้เป็นข้อผิดพลาด | "ผู้สร้างจากไปแล้ว งานยังเดินต่อ" | รอง |
| 9N | บันทึก: ทะเลที่พื้นหาย | | "ตรงนี้ปากกาเริ่มลบแล้ว ลบพื้นก่อน เหลือน้ำไว้" | รอง |
| 9B | เลวีอาธาน | | "ทะเลยังจำได้ว่าเคยมีพื้น" | เสริม |
| 10N | บันทึก: ภูเขาที่ตื่น | บันทึกสุดท้าย ลายมือสั่น | "หน้าถัดไปข้าวาดไม่ได้ ข้าไม่เคยไปถึง เจ้าต้องวาดเอง" | หลัก |
| 10B | เจ้าแห่งเพลิง | | "ข้าเป็นภูเขาก่อนพวกเจ้ามีไฟ" | เสริม |
| 11A | โต๊ะของผู้สร้าง | สถานที่ที่โลกถูกสร้าง หน้ากระดาษลอยอยู่ Aeon กำลังลบ ขอบแผนที่ในมือปาร์ตี้เริ่มหาย | (ไม่มีบทพูด ใช้ภาพ) | หลัก |
| 11B | หน้าของเจ้า | Aeon ชูหน้ากระดาษของโลกปาร์ตี้ ลบทีละเส้น สมาชิกปาร์ตี้กะพริบหายทีละคนแล้วกลับมา | "ข้าสร้างโลกทั้งหลาย แล้วข้าก็เบื่อ ของเจ้าคือหน้าสุดท้าย" | หลัก |
| 11C | ใบแรกของอีกมากมาย | ปากกาหล่น ปาร์ตี้เก็บปากกา วางแผนที่ของออร์รินลงบนหน้าว่าง แล้วลากเส้นแรก | "โลกใบสุดท้าย กลับเป็นใบแรกของอีกมากมาย" | หลัก |

## 7. ฉากจะอยู่ตรงไหนในเกม

## 10. สิ่งที่ตัดสินแล้ว

เจ้าของเกมให้ตัดสินเอง ("คิดเองเลย ทำให้ดีและสนุก") เปลี่ยนได้ทุกข้อ:

1. **Xal'Zhul เป็นคนร้ายที่มีเหตุผล** — เขากลืนแดนเพื่อซ่อนจากผู้ลบ องก์ 2 จึงต่อจากองก์ 1 เป็นเรื่องเดียว
2. **ใช้ชื่อ "ออร์ริน" (Orrin)** — สั้น จำง่าย อ่านได้ทั้งสองภาษา
3. **เก็บฉาก 11D แต่ไม่ให้เขากลับมา** — เกวียนว่าง ผ้าพันมือสะอาดผูกอยู่ กาน้ำชายังมีไอ นกกลับมาร้อง ผู้เล่นตีความเองว่าเขายังอยู่หรือไม่ การตายของเขาจึงยังหนักเท่าเดิม
4. **บทพูดแบ่งตามตำแหน่ง ไม่แบ่งตามอาชีพ** — และให้แต่ละตำแหน่งมีนิสัย: *คนนำ* พูดน้อย ตัดสินใจ, *คนที่สอง* ช่างสงสัยและปากไว (ที่มาของมุกเกือบทั้งหมด), *คนที่สาม* ไม่พูด ใช้ท่าทาง

สิ่งที่เพิ่มเพื่อให้สนุกขึ้น:
- **มุกชาขม** (เบาะแสข้อ 7) และ **มุก "ลุงมาถึงก่อนได้ยังไง"** ที่คนที่สองถามทุกแดน
- **บันทึกขอบแผนที่มีอารมณ์ขันของออร์ริน** เพื่อให้เขายังอยู่กับผู้เล่นในองก์ 2
- **ประโยค "ลากเส้นให้หนัก อย่าขอโทษเส้นที่เบี้ยว"** ที่ออร์รินเขียนในบันทึกสุดท้าย แล้วคนนำพูดซ้ำตอนจบ
- **ผู้พิทักษ์ทั้งห้าไม่ฟื้น** เมื่อแดนไหลกลับออกมา นี่คือราคาที่ปาร์ตี้จ่ายไปจริง

## 12. โค้ดและวิธีทดสอบ
